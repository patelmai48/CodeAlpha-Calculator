# Calculator-Project

A basic calculator application built using HTML, CSS, and JavaScript.

## Overview

This project performs standard arithmetic operations through an easy-to-use interface.

## Features

* Addition
* Subtraction
* Multiplication
* Division
* Clear button
* Responsive design

## Technologies Used

* HTML5
* CSS3
* JavaScript

## Learning Outcomes

* User input processing
* Basic mathematical operations
